# Expense Tracker V6 Final

## Run locally

```cmd
cd expense-tracker-v6-final
npm install
npm run dev
```

Open the local address shown by Vite, normally http://localhost:5173/.

## Production test

```cmd
npm run build
npm run preview
```

## Storage

The app stores data in browser localStorage under `expense-tracker-v6-final`.
Use Settings > Data backup to export a JSON backup regularly.
